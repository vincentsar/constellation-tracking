# Use established text collaboration with preserved merge state

The user agreed to React/SVG for the board and Tiptap/Yjs with local Hocuspocus for concurrent transcript editing, while a Node/Fastify host orders board commands on macOS or Windows. Established text collaboration avoids implementing a text merge protocol, but preserving Yjs identity requires an encoded checkpoint in the readable JSON session envelope; restarting from transcript content alone can duplicate content on reconnection. This records an individual interview decision and does not change the agreed host ordering of board fields or constitute complete specification acceptance.

Source: [Hocuspocus persistence guidance](https://tiptap.dev/docs/hocuspocus/guides/persistence).
