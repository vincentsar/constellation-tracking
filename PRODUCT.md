# Constellation tracker

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

The accepted specification selects React/TypeScript/Vite, an SVG board, Tiptap/Yjs/Hocuspocus text collaboration, and a Node/Fastify local host with portable JSON and generated Markdown/PNG.

## Users and purpose

Two editors record spatial arrangements and attributable conversations during therapy or systemic constellation sessions. Representatives and the roles they represent remain distinct. Editors can navigate independently while sharing one session.

## Operating context

Desktop/laptop browsers on a local network. The host runs on Windows or macOS. A session moves through editable slides. Automatic host persistence must be visible separately from connection and preview generation. All assets work locally.

## Capabilities and constraints

See the accepted task specification in docs/tasks/79338d1d-3929-47ae-84f2-2b75b0b9edc4/specification.md. Code-required joining is unresolved and must refuse startup when enabled until implemented. Cross-platform verification requires real macOS and Windows evidence.

## Product principles

- Preserve assignment identity as names change.
- Keep shared content separate from personal navigation and label preferences.
- Preserve drafts and explain conflicts.
- Acknowledgment follows host persistence.

## Open decisions

No established visual identity exists. Implementation assumes a quiet, light workspace; an optional preference question was sent during implementation.
